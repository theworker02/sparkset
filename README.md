# sparkset

Spark filesystem set paths across POSIX and Windows conventions.

**Site:** https://theworker02.github.io/sparkset/

## Install / run

```bash
git clone https://github.com/theworker02/sparkset.git
cd sparkset
node src/cli.js
node --test
```
